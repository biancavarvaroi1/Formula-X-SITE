# Imagini Baltagul

Folder public pentru ilustrațiile lecției „Baltagul”.

Adăugați cele 18 fișiere `.webp` din arhiva „Baltagul-18-imagini-pentru-GitHub.zip”, prin **Add file → Upload files** în acest folder.

Fișiere așteptate: cautare.webp, drumul.webp, demascare.webp, vitoria.webp, marturia.webp, munteni.webp, lupu.webp, credinta.webp, final.webp, incipit.webp, dreptate.webp, exterior.webp, familie.webp, traditie.webp, interior.webp, compozitie.webp, praznic.webp, mit.webp.

Aceste imagini sunt publice. Eseurile și chestionarele plătite nu se încarcă în acest director.
